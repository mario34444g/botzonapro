# Bot Tribunal Supremo de ALP2

Bot de Telegram que simula una Corte Suprema con 9 magistrados IA para el grupo ALP2.

## Requisitos

- Python 3.8+
- python-telegram-bot
- requests

## Instalación

```bash
pip install python-telegram-bot requests
```

## Ejecución

```bash
python bot.py
```

## Características

- 🏛️ **9 Magistrados con IA** (5 conservadores, 4 liberales)
- 📜 **Constitución** con 10 enmiendas
- ⚖️ **Sistema de Common Law** con precedentes
- 🎙️ **Audiencias orales** interactivas
- 📚 **Registro de precedentes** para casos futuros

## Uso

1. Inicia el bot con `/start`
2. Navega usando los botones interactivos
3. Para presentar un caso, selecciona "Nuevo Caso"
4. Describe tu situación y opcionalmente abre audiencia oral
5. Los 9 magistrados votarán individualmente

## Tipos de Casos

- **Apelación**: Apelar sanciones injustas
- **Contencioso Administrativo**: Denunciar acciones de admins
- **Aclaración Constitucional**: Interpretar las reglas
